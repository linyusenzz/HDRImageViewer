# 查看器分析工具

右上角的分析按钮打开侧栏中的「分析」页。打开时会读取缺失或过期的预览数据；调整缩放、显示参数或切图后，可点击直方图右上角刷新。

普通 SDR 图片和 HDR 图片均可使用 RGB 直方图、亮度统计、色域图和像素取样。两类图片共用色彩管理预览；SDR 的 Direct2D 路径直接采集当前预览，不会为分析切换到另一套色彩转换。仅 Gain Map 图层对比要求图片包含可解码的增益图。

## RGB 直方图

- 红、绿、蓝三条曲线分别统计有效图片区域的显示映射后 scRGB 通道值，排除画布留白和非有限像素。
- 左半区使用 sRGB 编码刻度，从黑到当前 SDR 白点。中线对应当前预览使用的 SDR 白点，图下显示其 nits 值。
- 右半区为 SDR 白点以上的高光，每条虚线增加 1 EV，范围到 +6 EV。更高值归入末端，负通道值归入左端。
- 三通道共用纵轴，显示像素数量的平方根，方便同时观察主峰与少量高光。曲线填充仅用于辨认通道，不表示累计数量。
- 平均与峰值亮度使用线性 RGB 的加权亮度；RGB 曲线横轴表示各通道值。这些值描述预览，不是源文件原始亮度或屏幕实测亮度。

分析在分屏覆盖前采集。鼠标移动至图片时显示预览像素坐标、亮度和线性 scRGB。画面变化后，旧快照不会继续作为有效取样数据。当前采集上限为 850 万预览像素，超出时需缩小窗口。

## HDR / SDR 分屏

「画面辅助」中的分屏对比开启后展开比例控制，右上角重置按钮可关闭分屏。

开启分屏对比后，左侧为 SDR，右侧为自适应 HDR，图片上显示对应标识；可拖动圆形手柄或侧栏滑块，并查看两侧比例。双击分界线或点击「居中」恢复 50 / 50。两侧共享缩放与平移位置。

## 色域图

侧栏「色域」页显示 CIE 1931 xy 马蹄图，点云统计当前可见区域的显示映射后 scRGB 预览颜色，亮度表示该坐标附近的像素密度。它不代表源文件或显示器的色域覆盖率。页面打开时会刷新缺失或过期的分析，也可手动刷新。

移动指针到图片，十字标记显示最近取样点，下方给出 xy 坐标及其相对于 sRGB、Display P3、BT.2020 边界的位置。三个边界可分别隐藏；D65 为参考白点。刷新、换图或预览变化后，旧取样标记会清除。黑色、非有限值和无效 XYZ 不计入点云，坐标范围为 x 0–0.8、y 0–0.9。

scRGB 按线性 BT.709 原色、D65 白点换算 XYZ，再归一化为 xy；换算前不裁掉负 RGB 分量。点云聚合到 160 × 180 个网格，背景颜色只是屏幕上的示意色。马蹄边界来自 [CIE 1931 标准观察者数据](https://doi.org/10.25039/CIE.DS.xvudnb9b)，保留来源与 CC BY-SA 4.0 许可说明于 `Rendering/Data/NOTICE.md`。

## 批量导出

顶部批量导出按钮打开独立窗口。添加文件、选择格式与保存文件夹后开始；队列逐张执行，单项失败后继续，支持取消与重试未完成项目。生成的文件名自动避开已有文件。队列保存在当前窗口内，关闭窗口会取消剩余任务。

SDR 导出使用固定色调映射，不应用查看器的当前显示调整；元数据与动态照片内容不保留。不同 HDR 格式仍需要相应的本机解码与编码依赖。
